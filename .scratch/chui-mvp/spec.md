# 锤锤影视 — MVP 规格

> 状态：draft（由 `/grill-with-docs` 定稿；2026-08 随"自建极简壳"转向修订，见 ADR-0004/0005）
> 关联：`CONTEXT.md` 词表、`docs/adr/0001–0005`
> 应用名：锤锤影视 · `applicationId: com.chuichui.video` · 工程根：仓库根（`app/` 模块）

## 定位

自用研究的影视播放客户端，跑在 **Android 手机 + Android TV（小米电视）** 上。作为"空壳"，零内置内容，通过用户导入的订阅配置调用第三方内容源，聚合、搜索、播放。目标用户：本人 + 低配电视。

## 平台 / 技术栈

- Android 手机 + Android TV（leanback）双形态，同一工程（`mobile` / `leanback` flavor）。
- **Kotlin + Jetpack Compose（含 Compose for TV）**（ADR-0005，2026-08 重定，取代原"Java + 经典 View"）。
- 播放：**ExoPlayer / Media3（公开坐标，硬解）**。
- 源解析：苹果 CMS(maccms) 采集 API 适配器 + **JS 蜘蛛**适配器（Rhino 轻量桥），统一 `SourceAdapter` 接口。

## 领域术语（见 CONTEXT.md）

片源 / 电影 / 剧集 / 集 / **分类** / 源 / 线路 / 播放地址 / 订阅配置 / 空壳

## MVP 功能范围（精简版）

1. **订阅导入与管理**（基础能力）：导入订阅配置（链接/文件/粘贴），源列表查看、启用/停用、删除；支持多份订阅。
2. **分类 / 首页浏览**：按分类拉取片源列表；电视端分类首页（leanback 焦点导航）。
3. **搜索**：关键词搜索片源。
4. **播放**：选集 + 换线路/换源（多源故障切换手动兜底）；下载解析地址后播放。
5. **观看历史**：本地记录（Room），续播记忆。

### 性能红线（低配电视）

- 所有源解析放后台线程 + 两级缓存（内存 + Room）。
- 电视端默认较低码率线路，可手动调清晰度。
- 原生轻量 leanback UI，虚拟化列表，禁重特效/模糊/大图。
- Media3 硬解。

## 明确不做（v1）

- 收藏 / 想看（标准版再做）
- 剧集自动连播 / 跳过片头片尾 / 倍速 / 字幕（完整版再做）
- 云同步 / 自建后端 / 跨源聚合去重 / 统一搜索
- 应用内置任何具体内容源（保持空壳，规避合规风险）

## 候选源协议（适配层）

- catvod 蜘蛛/JS 配置（`源 → 线路 → 播放地址` 依 spider 解析）
- 苹果 CMS 采集 API（`/api.php/provide/vod/?ac=list`、`?ac=detail`；`vod_play_from`=线路组、`vod_play_url`=线路分隔）
- 内部规范统一为：`片源 → 源 → 线路 → 播放地址`
