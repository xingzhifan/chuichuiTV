# 锤锤影视 — UI 视觉重做规格

> 状态：draft（由 `/grill-with-docs` 定稿；2026-09 用户明确"界面太丑，参考腾讯视频"启动）
> 关联：`CONTEXT.md` 词表（片源/源/线路/播放地址）、`docs/adr/0005`（性能红线）、`docs/adr/0003`（抗源失效）
> 范围：手机 + 电视（leanback）双端 UI 全面重做。仅 UI 层，不动领域/适配/播放逻辑。

## 目标与范围

- **范围**：把当前"纯文本列表"的 Compose UI 重做为"腾讯视频风格"的暗色海报卡片 UI，覆盖首页(分类)、片源列表、搜索、详情、历史、页面过渡。
- **明确不做**：不动播放器内核、源适配层、订阅逻辑（`api/`、`play/`、`subscription/` 的 Java 逻辑不改）；不做新的业务功能。
- **参考**：腾讯视频 —— 暗色主题、大封面、海报卡片网格、（克制地）渐变高亮、详情页大封面+集数列表。
- **约束（ADR-0005 性能红线）**：低配电视须流畅 —— 列表/网格**必须虚拟化**（`LazyColumn`/`LazyVerticalGrid`）、克制动画与层级、不滥用模糊/大图、海报用 Coil 异步加载+缓存。

## 关键决策

| 项 | 决策 |
|----|------|
| UI 框架 | 沿用 Kotlin + Jetpack Compose（含 M3），不加新框架 |
| 主题 | Material 3 **自定义暗色主题**：深蓝黑背景 + 蓝紫渐变高亮（`#5E35B1`→`#2979FF`）+ 白色文字 |
| 图片加载 | **Coil**（`io.coil-kt:coil-compose`）—— 新增硬前置依赖，渲染 `vodPic` 海报 |
| 首页形态 | 顶部源 chip 栏（保多源切换，立身之本）+ 分类"分组网格"呈现，告别纯文本 |
| 列表/网格 | 海报卡片 `PosterCard`：`8.dp` 圆角 + 渐变高亮边框/角标 + 标题 + 备注角标 |
| 过渡动画 | `NavHost` 系统 `enter/exitTransition`，克制淡入淡出，不用复杂转场 |
| 不动 | `api/`、`play/`、`subscription/` Java 逻辑、数据模型语义 |

## 工单清单

| # | 工单 | 说明 |
|---|---|---|
| 01 | 暗色主题 + 设计 Token | `ui/theme/`：`Color.kt`/`Type.kt`/`Theme.kt`，`MainActivity` 启用 |
| 02 | 图片加载 + PosterCard | 加 Coil；共享海报卡片组件作为全站基础 |
| 03 | 首页(分类)重做 | 源 chip 栏 + 分类分组网格 |
| 04 | 片源列表 + 搜索 重做 | 海报网格替换纯文本，保留无限滚动 |
| 05 | 详情页重做 | 大封面 + 梯度背景 + 线路分组 + 集数选择 |
| 06 | 历史页 + 过渡动画 | 历史改海报卡片；统一页面过渡 |

## 性能红线（必守）

- 所有列表/网格用 `Lazy*` 虚拟化。
- 克制动画：页面过渡用系统淡入淡出；卡片无入场动画洪峰。
- Coil `crossfade` 可开但保持小值；避免每项级联模糊。
- 海报容器固定宽高比（2:3），避免布局抖动。
