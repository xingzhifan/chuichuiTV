# 抗源失效：多源多线路故障切换 + 健康度检测 + 订阅自动刷新 + 本地缓存

用户导入的第三方源会经常失效，这是本应用的痛点。决策采用**纯客户端**分层冗余，把"源"当作可替换、可监测的资源池：

- **多源 + 多线路冗余**：同一片源聚合多个源，每个源多条线路；播放时按健康度排序尝试，失败自动切换下一线路/下一源，播放页可手动换源/换线路。
- **语义解耦 + 标准适配层**：内容(片源)与其来源解耦；用统一的"源适配器"把不同站格式（catvod 蜘蛛/JS、苹果 CMS 采集 API、m3u）归一化为内部规范，站点格式变化只影响对应适配器。
- **源健康度(liveness)**：每个源标记 up/down/unknown；后台轻量探测，失败者自动降权/标失效；UI 提供源列表、一键测速、启用/停用。
- **订阅配置自动刷新**：订阅为可配置链接，应用定时重拉保持新鲜；支持多份订阅避免单点失效。
- **本地缓存**：Room 缓存元数据、解析到的播放地址、各源健康历史，带过期策略，源抖动时用缓存兜底并加速二次浏览。

诚实边界：无法根治第三方源整站失效；本设计保证"一个源挂了用户几乎无感"且换源维护成本低。
